Public Cloud Manufacturing APIs & MCP Server

Dry Machina provides deterministic Cloud Edge REST endpoints and an autonomous Model Context Protocol (MCP) Server for algorithmic CAM toolpath compilation, G-code optimization, 5-layer machine safety audits, and multi-firmware macro compilation.

🤖 Remote MCP Server (Claude Desktop & Cursor IDE)
Hosted at drymachina.com/api/mcp

Connect Claude, Cursor, Antigravity, or custom agents directly to Dry Machina's safety shield and parametric generators:

1. Cursor IDE Config (.cursor/mcp.json)

{
  "mcpServers": {
    "dry-machina": {
      "url": "https://drymachina.com/api/mcp"
    }
  }
}

2. Claude Desktop Config (claude_desktop_config.json)

{
  "mcpServers": {
    "dry-machina": {
      "command": "npx",
      "args": ["-y", "@drymachina/mcp"]
    }
  }
}

REST API Endpoints

GET /api/macros

List all production parameterized machine macros and schema parameters.

curl -X GET https://drymachina.com/api/macros
POST /api/macros

Compile a parameterized macro into native Klipper (.cfg), Marlin, Bambu, or Dry IR.

curl -X POST https://drymachina.com/api/macros \
  -H "Content-Type: application/json" \
  -d '{
    "macro_id": "adaptive_purge_line",
    "target": "klipper",
    "params": { "startX": 15, "startY": 15, "length": 50 }
  }'
POST /api/verify

Run 5-layer machine envelope and melt flow safety audit on G-code.

curl -X POST https://drymachina.com/api/verify \
  -H "Content-Type: application/json" \
  -d '{
    "machine_id": "bambu_x1c",
    "gcode": "G90\nG0 X10 Y10 Z0.2 F6000\nG1 X50 Y10 E2.5 F1800"
  }'
GET /api/machines

Query physical build envelopes, max feedrates, and hotend melt limits for 24+ machines.

curl -X GET https://drymachina.com/api/machines
