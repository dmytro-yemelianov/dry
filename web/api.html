Local MCP & Catalog APIs

Run the published MCP package locally and use the Pages catalog helpers for machine and macro data. Hosted verification is a separate authenticated asynchronous service; no live public origin is claimed until its deployment and launch gates are complete.

🤖 Local MCP Server
Published as @dry/mcp

Start the package on your machine. The former unauthenticated Pages MCP endpoint is retired and is not a hosted verification tier:

Claude Desktop / local MCP client config

{
  "mcpServers": {
    "dry-machina": {
      "command": "npx",
      "args": ["-y", "@dry/mcp"]
    }
  }
}

REST API Endpoints

GET /api/macros

List all production parameterized machine macros and schema parameters.

curl -X GET https://drymachina.com/api/macros
POST /api/macros

Compile a parameterized macro into native Klipper (.cfg), Marlin, Bambu, or Dry IR.

curl -X POST https://drymachina.com/api/macros \
  -H "Content-Type: application/json" \
  -d '{
    "macro_id": "adaptive_purge_line",
    "target": "klipper",
    "params": { "startX": 15, "startY": 15, "length": 50 }
  }'
GET /api/machines

Query physical build envelopes, max feedrates, and hotend melt limits for 24+ machines.

curl -X GET https://drymachina.com/api/machines
