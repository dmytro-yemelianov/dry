# Design: Governance, support & legal hygiene (Slice G)

**Date:** 2026-06-29
**Status:** Approved — tracked in GitHub issues
**Branch:** `feat/governance` (off main)
**Source docs:** `docs/08-production-transition.md` (§WS7).

## Goal

Make the project **auditable and contributable** so external pilots can engage: a contributor guide, a
security policy, a support matrix, an operational provenance checklist, and a dependency-license audit.
Acceptance (08·WS7): a release can be audited for provenance + dependency licensing, and users know where
to report bugs and what support to expect.

## Artifacts

| Path | What |
|---|---|
| `CONTRIBUTING.md` | dev setup (build/test/`fmt`/`clippy` discipline), how to add conformance vectors/profiles, the clean-room rule, PR expectations |
| `SECURITY.md` | how to report a vulnerability, disclosure expectations, supported versions |
| `docs/16-support-matrix.md` | supported firmware/file-formats/platforms/workflows + support levels (ties to `14-known-limitations.md`) |
| `docs/17-provenance-and-licensing.md` | per-corpus provenance checklist (oracle-generated vs authored clean-room) + a runtime dependency-license audit |

`CLEANROOM.md` stays the *policy*; doc 17 is the *operational checklist + audit* that satisfies "a release
can be audited for provenance and dependency licensing".

## Provenance ledger (doc 17)

| Path | Origin | Clean-room status |
|---|---|---|
| `conformance/{gcode,gallery,golden,profiles,roundtrip,simulate}/` | generated by `conformance/export.py` from the FullControl oracle | output-only (no code copied); regenerate via the oracle |
| `conformance/oracle/` | the FullControl oracle generator | dev/CI only, excluded from releases |
| `conformance/{vectors,reports}/` | authored for the Dry spec/report slices | authored clean-room |
| `spec/examples/profiles/` | authored | authored clean-room |

Dependency-license audit: runtime deps are `serde`, `serde_json`, `miniz_oxide`, `libm` (core), `clap`
(CLI), `pyo3` (Python binding), `wasm-bindgen` (wasm binding) — all MIT/Apache-2.0/permissive; no GPL is
linked or shipped (the oracle is the only GPL dependency and is dev/CI-only).
